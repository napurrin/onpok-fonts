# 온폭 글꼴 (OnPok)

**폭 표에 있는 글자의 폭을 한글 문서에 자주 쓰는 글꼴에 맞춰, 같은 문서에서 줄바꿈이 같게 나오도록 만든 무료 글꼴입니다.**

한글(HWP·HWPX) 문서는 대부분 한컴·마이크로소프트 글꼴로 쓰입니다. 그 글꼴은 대부분 자유롭게 다시 배포할 수 없습니다(무료로 받을 수 있는 글꼴도 배포 조건이 따로 있습니다). 그래서 글꼴이 없는 PC·휴대폰이나 웹 뷰어에서는 다른 글꼴로 바꿔 그리게 되고, 글자 폭이 달라 줄바꿈이 어긋납니다.

온폭 글꼴은 무료 글꼴(Noto, 백묵)을 바탕으로, 폭 표에 있는 글자의 폭을 원래 글꼴의 폭과 같게 맞춘 글꼴입니다.
- 모양은 바탕 글꼴을 따르므로 원래 글꼴과 다릅니다.
- 굵기는 한컴에서 저장한 PDF와 획 농도가 비슷한 굵기를 골랐습니다. 모양이 다르므로 굵기도 똑같지는 않습니다.

> 「온폭」은 「폭이 꼭 맞는 글꼴」이라는 뜻입니다. 또고·코코·망고는 만든 사람 집의 애칭입니다.

**폭을 맞춘 범위**
- 폭 숫자는 [rhwp](https://github.com/edwardkim/rhwp)(MIT, Copyright (c) 2025-2026 Edward Kim)의 폭 표에서 가져왔습니다. 글자 모양은 쓰지 않았습니다. rhwp가 폭 표를 공개해 준 덕분에 만들 수 있었습니다.
- 폭 표에 있는 글자(글꼴마다 약 11,500자 — 한글 11,172자, 영문·숫자·문장 부호, 일부 한자·기호)는 글꼴 폭을 표의 폭과 똑같이 맞췄습니다. 표에 있는데 폭이 다른 글자는 모든 글꼴에서 0입니다(`CHECK_GLYPHS.md`).
- 폭 표에 없는 글자는 바탕 글꼴의 폭을 씁니다.
- 폭 표에 있지만 바탕 글꼴과 Noto 어디에도 없는 드문 글자(백묵 계열 ‛ ‾ 2자, 망고바탕·코코돋움의 드문 문장 부호·보이지 않는 글자 33자)는 아직 넣지 못했습니다. 이 글자는 다른 글꼴로 그려집니다.

**어디까지 확인했나**
- 표의 폭이 한컴의 실제 배치와 같은지는 공개 보도자료 10줄(글꼴 10개, 한 줄씩)로만 견줬습니다. 문서 전체의 줄바꿈·쪽 나눔은 확인하지 않았습니다.
- 그 10줄에서 한글 글자 폭(다음 글자까지의 거리)은 9개 글꼴이 모두 맞았고, 온폭 망고바탕은 21쌍 중 14쌍(67%)만 맞았습니다. 자세한 것은 `samples/README.md`에 있습니다.
- 비교 그림이 없는 글꼴(공개 보도자료에서 그 글꼴로만 쓰인 한글 위주 줄을 찾지 못함): 새명조·새명조 2, 중고딕·중고딕 2, 견명조·견명조 2, 견고딕·견고딕 2, 굴림체, 돋움, 또고딕·망고바탕·코코돋움의 굵게. 이 글꼴들은 폭 표와 같은지만 확인했습니다.

**빠진 글자 채움:** 공문서에 자주 나오는 문자가 모든 온폭 글꼴에 들어 있게 채웠습니다.

**상표:** 표에 적은 글꼴 이름(맑은 고딕, 굴림·돋움·바탕(체), 휴먼○○, 한양○○, HY○○, 함초롬○○ 등)은 각 권리자의 상표입니다. 온폭 글꼴은 그 회사들과 관계가 없습니다. 이 이름들은 「어떤 글꼴과 폭을 맞췄는지」를 알려 주는 설명으로만 씁니다. 온폭 글꼴 이름 속 「굴림·돋움·바탕·명조·고딕」은 글꼴 갈래를 뜻하는 일반 낱말로 썼습니다.

## 설치

- **윈도우:** `fonts/ttf`의 파일을 오른쪽 단추로 눌러 「설치」(여러 개는 모두 골라 한 번에)
- **맥:** 파일을 두 번 눌러 「서체 관리자」에서 설치
- **웹:** `fonts/woff2`를 서버에 두고 아래처럼 씁니다.

```css
@font-face {
  font-family: "OnPok Mango Batang";
  src: url("fonts/woff2/OnPok-MangoBatang.woff2") format("woff2");
  font-weight: 400;
}
@font-face {
  font-family: "OnPok Mango Batang";
  src: url("fonts/woff2/OnPok-MangoBatangBold.woff2") format("woff2");
  font-weight: 700;
}
/* 한글 문서 뷰어에서: 원래 글꼴이 없을 때 온폭으로 */
.hwp-page { font-family: "함초롬바탕", "OnPok Mango Batang", serif; }
```

**한글 문서 뷰어·편집기를 만드는 분께**
- 문서가 「함초롬바탕」을 요구하는데 그 글꼴이 없으면, 「온폭 망고바탕」으로 바꿔 그리면 폭 표에 있는 글자의 폭이 같아집니다.
- 위 표를 대체 글꼴 표로 쓰실 수 있습니다.
