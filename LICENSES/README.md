# 글꼴별 라이선스

온폭 글꼴은 두 가지 무료 글꼴을 바탕으로 고친 것입니다. 바탕에 따라 라이선스가 다릅니다.

| 온폭 글꼴 | 바탕 글꼴 | 라이선스 |
|---|---|---|
| 온폭 명조, 새명조, 새명조 2, 견명조, 견명조 2, 망고바탕(보통·굵게) | Noto Serif KR | SIL Open Font License 1.1 — `OFL-1.1.txt` |
| 온폭 고딕, 또고딕(보통·굵게), 중고딕, 중고딕 2, 견고딕, 견고딕 2, 제목고딕, 코코돋움(보통·굵게) | Noto Sans KR | SIL Open Font License 1.1 — `OFL-1.1.txt` |
| 온폭 굴림, 굴림체, 돋움, 돋움체 | 백묵 굴림·돋움 + **Noto Sans KR 일부 글자** | SIL Open Font License 1.1(글꼴 전체) **+ 백묵 허가 문구 유지** — `OFL-1.1.txt`, `Baekmuk-COPYRIGHT.txt` |
| 온폭 바탕, 바탕체 | 백묵 바탕 + **Noto Serif KR 일부 글자** | SIL Open Font License 1.1(글꼴 전체) **+ 백묵 허가 문구 유지** — `OFL-1.1.txt`, `Baekmuk-COPYRIGHT.txt` |

**백묵 글꼴에 넣은 Noto 글자:** 백묵 글꼴에 없던 줄표(— – ‒), 원 숫자 ⑯~⑳, 괄호 숫자 ⒃~⒇, 통화 기호(₩ € £ ¥), 점(• ‧), 악센트 붙은 로마자(À é 등) 같은 글자를 같은 계열 Noto(Sans KR·Serif KR)에서 가져와 채웠습니다.
- OFL 1.1 조건 5에 따라, Noto 글자가 들어간 글꼴은 전체를 OFL 1.1로 배포합니다.
- 백묵 허가 문구가 요구하는 저작권 문구, 허가 문구, 등록상표 문구는 그대로 둡니다.

**다른 Noto 글꼴에서 가져온 글자** — 모두 SIL Open Font License 1.1입니다. 글꼴 안 name 표(ID 0·13)에 저작권과 라이선스를 적었습니다.
- **Noto Sans CJK KR:** 고딕 계열 온폭 글꼴에 없던 隙(U+9699)는 Noto Sans KR에도 없어서 여기서 가져왔습니다. 저작권 문구(Copyright 2014-2021 Adobe, with Reserved Font Name 'Source')가 Noto Sans KR과 같습니다.
- **Noto Sans Symbols · Noto Sans Symbols 2:** 글머리 기호(⌛ ▸ ☐ ✓ 🔾 🔿 등)와 점(∙) 일부. Copyright 2022 The Noto Project Authors (https://github.com/notofonts/symbols)
- **Noto Sans Math:** 폭 표에 있는 수학 기호(≒ ≈ ⊂ 등) 일부. Copyright 2022 The Noto Project Authors (https://github.com/notofonts/math)

**폭 숫자 — rhwp:** 글자 폭 숫자는 rhwp(MIT, Copyright (c) 2025-2026 Edward Kim)의 폭 표에서 가져왔습니다. 글자 모양은 쓰지 않았습니다. MIT 고지는 `rhwp-MIT.txt`에 있습니다.

## 지켜야 할 것

- **OFL(모든 온폭 글꼴):** 자유롭게 쓰고, 고치고, 다시 배포할 수 있습니다. 다만 아래를 지켜야 합니다.
  - 글꼴만 따로 팔 수는 없습니다.
  - 고친 글꼴도 OFL로 내야 합니다.
  - Noto Sans KR의 예약 이름 「Source」는 쓰지 않습니다. 온폭 이름에도 들어 있지 않습니다.
- **백묵 바탕 글꼴(굴림·굴림체·돋움·돋움체·바탕·바탕체):** OFL에 더해 아래 두 가지를 지킵니다.
  - 모든 사본에 백묵 저작권 문구와 허가 문구를 함께 둡니다(`Baekmuk-COPYRIGHT.txt`, 글꼴 안 name 표).
  - 함께 배포하는 문서에 아래 문구를 표시합니다.

> 백묵 바탕, 백묵 돋음, 백묵 굴림, 백묵 헤드라인은 김정환의 등록상표입니다.
